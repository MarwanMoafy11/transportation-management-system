\# Transportation Management System



A desktop-based Transportation Management System inspired by ride-hailing applications such as Uber.



\## Features



\- User registration and login

\- Driver registration and management

\- Vehicle management

\- Ride booking system

\- Ride filtering by location and vehicle type

\- Promo code management

\- SQL-based reporting and analytics

\- Windows Forms graphical interface



\## Technologies Used



\- C#

\- .NET Framework 4.7.2

\- Windows Forms

\- SQL Server



\## Database Features



\- Relational database design

\- Foreign key constraints

\- SQL JOIN queries

\- Driver-vehicle relationships

\- Ride analytics queries

\## How to Run



1\. Open the project in Visual Studio.

2\. Restore the SQL Server database using the provided SQL scripts.

3\. Update the SQL connection string if necessary.

4\. Run the application.



\## SQL Files



\- `DDL.sql` → database schema and table creation

\- `SQLQuery1.sql` → sample queries and analytics
